# InsightFlow walkthrough

1. Open the app and choose a sample or upload any CSV/Excel file.
2. Inspect inferred numeric, categorical and date fields.
3. Review suggested interactive charts.
4. Explore numeric measures and groups.
5. If at least eight time periods exist, view a basic linear trend projection.
